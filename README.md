# t-silverthorne.github.io

Academic website for Turner Silverthorne.

## Preview locally

This is currently a dependency-free static site. From the repository root, run:

```powershell
npm run preview
```

Then open <http://localhost:8000> in a browser. Stop the server with `Ctrl+C`.

You can also open `index.html` directly, but using the local server is the better preview because it matches how the site will be served.

The initial content and structure are based on `../invoice-template/cv-2026/main.tex`. Update `index.html` for content and `styles.css` for visual styling.
